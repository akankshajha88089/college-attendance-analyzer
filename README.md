 # PS No. 9: College Attendance Analyzer

## Project Overview
The **College Attendance Analyzer** is a Python-based data analysis tool designed to evaluate student attendance records from a CSV file. It calculates attendance percentages, identifies students with attendance shortages below the mandatory 75% threshold, handles data validation errors, and visualizes overall attendance trends using Matplotlib charts.

---

## Objectives
- Read and process student attendance datasets stored in CSV format.
- Calculate individual student attendance percentages accurately.
- Filter out students who fall short of the minimum 75% attendance criteria.
- Handle data validation cases (e.g., attended classes exceeding total classes held).
- Generate visual insights using Matplotlib (Bar and Pie charts) for subject-wise performance analysis.

---

## Features
- **Attendance Percentage Calculation:** Automatically computes attendance % for each student record.
- **Shortage List Generation:** Identifies and displays students with attendance below 75% using Pandas boolean filtering.
- **Data Validation & Error Handling:** Automatically skips rows with invalid data (e.g., `Classes_Attended > Classes_Held`).
- **Subject-wise Trend Analysis:** Calculates average attendance percentages categorized by subject.
- **Data Visualization:** Generates Bar Charts and Pie Charts to visualize attendance distribution and subject performance.

---

## Technical Stack & Requirements
- **Language:** Python 3.x
- **Libraries Required:**
  - `pandas` (for CSV parsing and data filtering)
  - `matplotlib` (for visual data representation)

### Installation Command
To install the required libraries, run:
```bash
pip install pandas matplotlib
